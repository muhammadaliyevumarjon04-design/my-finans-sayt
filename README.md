# Расход — публикация на GitHub Pages

## Как опубликовать сайт

1. На GitHub создай новый **Public**-репозиторий. Например, `rashod`.
2. Распакуй этот архив на компьютере.
3. Загрузи **содержимое папки** в корень репозитория (не саму папку `rashod-github-pages`). В корне должны быть `package.json`, `vite.config.ts` и папка `src`.
4. Сделай commit в ветку `main`.
5. Открой репозиторий → **Settings → Pages**.
6. В разделе **Build and deployment** выбери **GitHub Actions** как Source.
7. Открой вкладку **Actions** и дождись завершения процесса **Deploy to GitHub Pages**.
8. После успешного запуска адрес сайта будет примерно таким: `https://ТВОЙ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

При каждом следующем push в `main` сайт будет автоматически пересобираться и обновляться.

## Важно про личные данные

Приложение хранит данные расходов в `localStorage` браузера. GitHub Pages публикует только файлы сайта и не получает содержимое хранилища браузера посетителей. Данные разных пользователей не объединяются.

## Запуск на компьютере (необязательно)

Нужен Node.js 20.19+ или 22.12+:

```bash
npm ci
npm run dev
```
